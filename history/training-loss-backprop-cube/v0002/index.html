1. 先看全景：训练到底在做什么

本页以自回归语言模型、one-hot 监督及普通反向传播为背景，只讨论训练目标与参数更新，不展开硬件实现。

损失定义怎样算好；反向传播计算参数如何影响好坏；优化器决定具体怎么改。

2. 交叉熵为什么是正确答案概率的负对数

预训练把文本变成预测下一个 token 的任务。模型对词表中的每个候选输出一个分数 zi，称为 logit，再通过 softmax 得到概率：

pi = exp(zi) / Σj exp(zj)

目标分布记为 q。若正确答案是第一个词，通常 q = [1, 0, 0, …]，即 one-hot 分布。交叉熵为：

L = −Σi qi log pi = −log py

其依据是最大似然估计。文本序列的概率可分解为各位置条件概率的乘积；取对数后，乘积成为求和；加负号，把最大化转成最小化：

Pθ(x1, …, xT) = ∏t Pθ(xt | x<t)

L(θ) = −(1/T) Σt log Pθ(xt | x<t)

实际常对参与监督的有效 token 求平均，忽略 padding 或被屏蔽的位置。上述是常见预训练／监督微调目标；偏好优化等后训练阶段可以采用其他目标。

3. 为什么对 logit 求导，得到 pᵢ − qᵢ

对 zi 求导，是为了知道这个输出分数提高一点，最终损失如何变化。这是继续求模型参数梯度的中间步骤，不是最终更新对象。

先把 softmax 代入损失

log pj = zj − log(Σk exp(zk))

利用 Σj qj = 1，可化简为：

L = −Σj qjzj + log(Σk exp(zk))

分别求两项的导数

项对 zᵢ 的偏导原因
−Σⱼ qⱼzⱼ−qᵢ只有第 i 项含有 zᵢ，目标 q 固定
log(Σₖ exp(zₖ))exp(zᵢ) / Σₖ exp(zₖ) = pᵢ应用 log 的求导法则和链式法则

相加得到：∂L/∂zi = pi − qi。

例如 p = [0.6, 0.3, 0.1]，q = [1, 0, 0]，输出端梯度就是 [−0.4, 0.3, 0.1]。如果直接对 logits 做梯度下降，会提高正确词的分数，降低其他词的分数。实际训练则通过这些梯度更新模型权重。

目标是 one-hot，为什么错误词也有梯度？

即使 L = −log p1，p1 的分母仍包含所有 logits：

L = −z1 + log(exp(z1) + exp(z2) + exp(z3))

提高错误词分数，会增大分母、降低正确词概率，因而提高 loss。qi = 0 不代表该输出没有梯度。以上公式按单个监督位置书写；平均损失还会带来相应的缩放系数。

4. θ 是什么，为什么参数梯度里还有求和

θ 通常统指所有可训练参数，θj 表示其中一个标量参数。例如简单模型 ŷ = wx + b 中，θ = {w, b}。大模型中包括 Embedding、注意力投影矩阵、MLP 权重、归一化参数、输出层权重，以及架构中存在的偏置。

每个权重矩阵里的每一个数，都是一个参数。输入 token、中间激活 h 和 logits z 通常是数据或计算结果，不是被优化器直接保存和更新的权重。

同一个参数可能影响多个 logits，所以必须汇总所有路径的贡献：

∂L/∂θj = Σi (pi − qi) · ∂zi/∂θj

  • i：输出／词表位置的编号；求和完成后它消失。
  • j：参数的编号；每个参数最终得到自己的梯度。
  • 不是直接把所有 pi − qi 相加，而是先乘以该参数对对应输出的影响。
链式法则：沿路径相乘，多条路径汇合时相加。不会把所有参数的梯度加成一个数。

5. 第一层也对最终 loss 求导，但要逐层反传

用只有三个标量权重的简化网络说明：

x --[ × w1 ]--> h1 --[ × w2 ]--> h2 --[ × w3 ]--> y_hat

h1 = w1x；h2 = w2h1；ŷ = w3h2；L = ½(ŷ − y)2。

位置传入梯度本层权重梯度继续向前传递
第三层g₃ = ŷ − y∂L/∂w₃ = g₃h₂g₂ = g₃w₃
第二层g₂∂L/∂w₂ = g₂h₁g₁ = g₂w₂
第一层g₁∂L/∂w₁ = g₁x若需要，继续求输入梯度

展开第一层梯度：

∂L/∂w1 = (ŷ − y) · w3 · w2 · x

所以数学上确实是“最终 loss 对第一层权重求导”；计算上则复用后面各层已经算出的梯度，逐层向前传播。真实网络还包含激活函数、注意力、残差分支等，其局部导数会加入这条链。

通常一次反向传播算完各层梯度后，优化器才更新参数。不是先更新最后一层，再使用更新后的权重计算第一层梯度。

6. 优化器接手：梯度怎样变成参数更新

反向传播只负责求出梯度 gt = ∂L/∂θ，优化器负责使用它。

SGD：沿负梯度方向迈一步

θt+1 = θt − ηgt

η 是学习率。例如参数为 0.8，梯度为 0.2，学习率为 0.01，则更新后为 0.798。

AdamW：还使用梯度的历史状态

它维护一阶矩 m 和二阶矩 v：

mt = β1mt−1 + (1−β1)gt

vt = β2vt−1 + (1−β2)gt2

再结合偏差修正、开方、除法、学习率及解耦权重衰减等完成逐元素更新。这里是机制摘要，不是完整实现公式。

optimizer.zero_grad()
logits = model(inputs)
loss = loss_fn(logits, targets)

loss.backward()    # 计算梯度，写入参数的 .grad
optimizer.step()   # 根据梯度和优化器状态更新参数

梯度不是应用到 loss 数值上，而是用于修改参数，让后续计算的 loss 倾向于更低。不保证每一步、每个批次的 loss 都下降。
